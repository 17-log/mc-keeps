# 麦门浪漫人格：功能、规则与隐私

本功能在现有 **mc-keeps** 仓库中扩展照片手帐，以「你把日子，吃成了哪种浪漫？」邀请用户完成生活场景小游戏，再将一个小任务带回自己的日记。本文依据当前 `p1` 源码描述行为，实际检查及设备范围见 [验证记录](personality-validation.md)；不承诺分享量、传播率或用户增长。

入口：<https://17-log.github.io/mc-keeps/#persona>。人格结果链接与二维码均使用这一原项目地址，保持 `p1` 结果兼容。

## 从答题到一页手帐

1. 进入人格首页，可先看 16 种角色图鉴；图鉴中的角色与刻度明确标为示例。
2. 回答 8 道生活场景题，每题选择一个选项；可以返回修改，完成后查看结果卡与评分解释。
3. 分享结果链接或保存带二维码的 PNG。朋友从深链先看到分享者的卡片，再选择自测；若本机已有完成结果，也可直接对照。
4. 对照显示共同偏好与不同节奏，给出可以一起体验的小建议。它不评价关系好坏，也没有匹配百分比。
5. 在自己的结果页点击「带着小任务，记一餐」，回到原有手帐编辑器。确认实际餐品、日期和照片，点击「收进日历」后才写入日记。

这条路径将自我表达、好友互动和实际生活记录连接起来。是否有人愿意分享、朋友是否完成自测、是否继续写日记，需要真实使用后评估。

## 8 题、4 轴与可解释评分

每个维度由 2 道题决定，各题 4 个选项依次记为 `−2`、`−1`、`+1`、`+2`，没有正确答案。四位角色码依照下表的顺序组成。

| 维度 | 左端 / 代码 | 右端 / 代码 | 题目位置 |
| --- | --- | --- | --- |
| 同行方式 `company` | 独享 / D | 搭子 / B | 第 1、5 题 |
| 小事仪式 `ritual` | 随性 / S | 仪式 / Y | 第 2、6 题 |
| 口味探索 `novelty` | 经典 / C | 探索 / T | 第 3、7 题 |
| 回忆习惯 `memory` | 当下 / X | 收藏 / Z | 第 4、8 题 |

每轴计算为：

```text
sum = 对应两题的选项分值之和            // −4 到 +4
score = Math.round((sum + 4) / 8 * 100) // 0 到 100
```

小于 50 取左侧代码，大于 50 取右侧代码。**等于 50 表示混合偏好**，为稳定展示角色固定取右侧代码，同时保留混合提示；不将平分解释成明确偏向。比如 `−2 + 1 = −1` 得到刻度 38，偏向左端；`−2 + 2 = 0` 得到 50，显示两端混合。

刻度只是本次答案的可复算表示，不是概率、排名、人口占比、稀有度或心理测量结论。相同有效答案会得到相同结果，答案不完整或越界时不生成有效结果。结果页可以展开规则；本机保有完整答案时，也能点开原题修改。

日记数量、照片、订单、金额、历史消费都不参与评分。结果页显示的本月日记 / 记录日 / 照片数量只是手帐上下文，不改变人格结果。

每种角色包含称号、副标题、短句、标签、生活描述和一个手帐小任务。它们是项目原创的生活偏好表达，不对应 MBTI 的 16 型，也没有经过科学量表验证。不要用结果推断能力、健康、职业适合度或亲密关系质量。

视觉使用 8 类原创 32 × 32 像素食物及表情变体：薯条、汉堡、汽水、咖啡、派、冰淇淋、鸡块与早餐。16 种角色通过食物、表情和配色组合表达；页面 SVG 与导出 Canvas 共用像素定义，没有使用参考测试的角色图片、题库或结果文案。

## 结果深链与好友对照

结果链接结构：

```text
https://17-log.github.io/mc-keeps/#persona?v=p1&r=<结果令牌>
结果令牌：p1.<四位角色码>.<八位摘要>
```

八位摘要按四条轴的顺序，将每条整数刻度编码为两个小写 base36 字符。这里只携带版本、角色码和四条刻度，不包含逐题答案、照片、日记正文、订单或 Token。生成链接时会清除基础地址的查询串，避免带入来源页面的临时参数。

接收方校验版本、参数数量、令牌格式、刻度范围，以及角色码和刻度是否相符；非法或不支持的链接回到带提示的入口，可以重新开始。令牌用于恢复卡片，不是加密、签名或身份凭证，不能据此证明某人确实作答。持有或转发链接的人可以查看该结果摘要。

UI 的分享基础地址固定为 `https://17-log.github.io/mc-keeps/`。即使从本地文件或本机服务体验，生成的分享链接也会指向这个公开站点；不是把本机地址发送给朋友。

朋友从链接进入时先看到原结果，再自测或选择本机上次完成的结果。对照逐轴区分左偏、右偏与混合，呈现「可以一起享受的」和「可以互相带一带的」；只比较本次选择，不给关系打分。

## 分享与 PNG

- 支持浏览器系统分享；不支持或失败时提供含二维码、链接和文案的分享弹窗。用户取消系统分享时可以继续浏览。
- 复制优先使用 Clipboard API；受限时尝试浏览器复制并提示手动选中链接。是否可调用系统分享或剪贴板，取决于设备和浏览器。
- 结果 PNG 尺寸为 **1080 × 1440**，包括像素角色、称号、短句、标签、四条偏好轴、娱乐定位提示和二维码。二维码与文本分享使用同一条公开结果链接。
- 二维码由本地打包的 `qrcode-generator` 2.0.4 生成，纠错等级 M；PNG 直接绘制二维码矩阵并保留四个模块的留白，不向第三方二维码网站提交结果。

保存 PNG 不会自动发到社交平台。下载、扫码、平台内置浏览器与转发后的显示效果需在目标设备和发布版本上验证；本说明不替代验证记录。

## 小任务如何接回原手帐

「带着小任务，记一餐」切换到个人空间，用当前本地日期打开原有的新建编辑器，预填角色相关的食物建议、标题、短句、小任务与心情。它不关联订单，不带入照片或金额；建议餐品不是已消费事实，需要本人确认或修改。

用户可编辑日期、餐品、标题、文字、照片等原有字段，最后主动保存。取消编辑不会写入一条日记，未保存草稿也不保证在刷新后保留。人格模块没有额外的任务完成率、连续打卡奖励或任务追踪系统。

原有 MCP 仍是本机版的独立只读订单连接。人格答题、结果分享和写草稿无需 MCP Token，不会因为测完人格而自动查询或操作订单。完整订单边界见 [MCP 接入说明](../MCP_INTEGRATION.md)。

## 本地保存与隐私

| 内容 | 当前保存位置 / 范围 |
| --- | --- |
| 自己最近一次完成结果及 8 个答案 | 当前浏览器 `localStorage`，键 `mc-keeps-persona-p1`；用于「查看上次的我」与修改答案 |
| 朋友的结果摘要 | 当前标签页会话的 `sessionStorage`，键 `mc-keeps-persona-friend-p1`；用于接续对照 |
| 尚未完成的答题进度 | 页面运行内存，刷新后不保证恢复 |
| 照片与已保存的日记 | 原手帐 IndexedDB；不写入人格结果链接或人格 PNG |
| 主动分享的链接 / 人格 PNG | 持有者可查看或继续转发结果摘要；不需要登录 |

人格功能没有账号与云同步服务。存储被浏览器禁止时，本次仍可生成结果，但不保证恢复；清理网站数据或换浏览器会影响本地结果。原有日记 JSON 备份只备份日记，不包含上述人格 `localStorage` 与好友会话数据。

当前人格模块没有统计埋点，不提供访问人数、真实分享人数或转化率。后续如增加统计，应先说明采集范围，再分别观察开始答题、完成答题、点击分享、从结果链接打开、自测对照、打开草稿与确认保存。点击分享不等于成功发出，打开草稿不等于写下日记。

## 调研依据与设计判断

以下是公开来源与本项目的设计判断。它们说明相关玩法曾经存在，不能证明本项目一定获得相同传播效果。

| 公开来源 | 可支持的事实 / 本项目借鉴 |

| [You Simi Flavour 像素食物测试报道，Time Out](https://www.timeout.com/singapore/news/you-simi-flavour-potong-ice-cream-personality-quiz-080224) | 报道食物角色、生活问题和 8-bit 视觉的结合；本项目采用原创食物像素表达，另接回已有日记 |
| [小红书官方趣味测试作品频道](https://cowork.xiaohongshu.com/s/vibe-app-rank/) | 可见趣味测试这一作品类别；榜单口径不等于真实传播或转化数据，部分详情存在访问限制 |

据此提出的产品判断是：让用户认领一句像自己的文案，用结果链接邀请朋友继续，再把小任务写成有日期的一页。新的题目、轴、角色、文案、像素矩阵与手帐衔接均在本仓库独立实现；不使用虚假稀有度、匹配百分比、科学 MBTI 包装或虚构排行制造分享理由。
